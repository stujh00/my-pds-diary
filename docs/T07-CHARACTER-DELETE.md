# 캐릭터·알림·계획 삭제 적용

현재 005까지 적용한 배포 기준입니다. 이번 압축파일의 파일을 같은 경로에 덮어쓰며, 저장소 전체를 지우지 않습니다. 003/004를 재실행하지 않습니다.

1. Supabase SQL Editor에서 `supabase/006_profile_characters.sql` 실행.
2. 같은 SQL Editor의 새 쿼리에 `supabase/007_plan_delete.sql` 실행.
3. 수정 파일을 기존 GitHub 저장소에 업로드·커밋. Vercel Ready 확인 후 페이지 새로고침.

006은 프로필 표와 계정별 캐릭터 저장 RPC, 전체 내보내기에 프로필을 포함하는 snapshot을 추가합니다. 007은 계획 삭제 RPC를 추가합니다. SQL을 설치하는 것만으로 기존 계획을 삭제하거나 기존 기록 값을 바꾸지 않습니다. SQL 006/007은 재실행해도 기존 프로필과 자료를 초기화하지 않습니다.

## 짧은 확인 방법

- 어디로 가나요: 로그인 후 내 계정. 계획 삭제는 내 계획 화면.
- 세 단계 안에 무엇을 하나요: 캐릭터 선택 → 동물/과일 선택 → 저장. 삭제는 테스트 계획 선택 → 계획 삭제 → 확인 문구 입력 후 저장.
- 무엇이 보이면 통과인가요: 왼쪽 내 계정 메뉴 아래 원형 캐릭터, 새로고침 후 같은 선택. 저장 안내는 4초 후 사라짐. 삭제한 테스트 계획과 연결 자료가 목록·집계에서 사라지고 새로고침 후에도 없음.
- 안 될 때 무엇이 보이나요: 잘못된 삭제 확인 문구는 모달에 오류. 설치/서버/네트워크 문제는 DB 오류 안내. 5일 관찰에 사용한 근거가 있으면 근거 보존 때문에 삭제할 수 없다는 안내.

동물 18종: 고양이·강아지·토끼·곰·판다·여우·호랑이·사자·코알라·펭귄·개구리·햄스터·원숭이·돌고래·늑대·물개·상어·다람쥐.
과일 18종: 사과·배·귤·레몬·바나나·수박·포도·딸기·체리·복숭아·파인애플·키위·망고·메론·참외·자두·블루베리·아보카도.

캐릭터 선택을 닫기로 취소하면 저장하지 않습니다. 저장은 현재 로그인 계정에만 반영되며, 다른 기기에서도 같은 계정의 값을 복원합니다. 전체 JSON 내보내기에 프로필을 포함하고 계정 삭제 시 함께 삭제합니다. 캐릭터는 로컬 SVG 그림으로 표시되며 외부 이미지 서비스나 이모지 폰트에 의존하지 않습니다.

계획 삭제는 계획과 연결된 할 일(삭제 이력 포함)·실행 기록·완료 기록·돌아보기·수정 이력을 영구 삭제합니다. 그 돌아보기에서 만든 다음 계획은 유지됩니다. 5일 관찰에 이미 저장한 근거 실행 기록이 있는 계획은 삭제하지 않습니다. 계획 삭제 시험은 별도 테스트 계획으로 진행합니다.

## 캐릭터 12종 추가 적용

006/007까지 적용한 상태에서 `008_more_characters.sql`만 실행하고, 추가 캐릭터 ZIP 파일을 같은 저장소에 덮어씁니다. 이미 적용한 006을 다시 실행하지 않습니다. 008은 허용 목록과 저장 RPC 검증만 확장하며 기존 선택/갱신 시각/계획 자료는 바꾸지 않습니다. 캐릭터 선택 창에서 동물 18종·과일 18종이 보이고, 새 캐릭터를 저장한 뒤 새로고침해도 그대로이면 통과입니다. SQL이 빠지면 새 캐릭터를 저장할 때 허용 목록 오류가 표시됩니다.
