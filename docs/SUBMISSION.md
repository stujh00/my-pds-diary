1. 어디로 가나요: 결과물 URL을 시크릿 창에서 열고 ‘10월 24일 정보처리기사 실기 대비’ 계획을 선택합니다.
2. 세 단계 안에 무엇을 하나요: ① 할 일에서 실제 공부 기록을 추가합니다. ② 돌아보기에서 실제 시간 숫자를 누릅니다. ③ 새로고침합니다.
3. 무엇이 보이면 통과인가요: 입력한 기록이 근거 목록에 보이고 실제 시간 합계에 반영되며 새로고침 뒤에도 같은 ID·시각·분 단위 값으로 남습니다.
4. 안 될 때는 무엇이 보이나요: DB 설정·연결·입력 오류 메시지가 표시되며 저장 성공으로 표시되지 않습니다. 입력창의 오류를 확인하거나 환경변수/SQL 설치를 확인한 뒤 다시 시도합니다.
