# 실행한 로컬 검증과 남은 배포 확인

이 파일의 기록은 실제 5일 학습 기록이 아닙니다. 테스트용 PostgreSQL 데이터/날짜와 UI 모의 응답은 검사 환경에서만 사용했으며 사용자 계정에 삽입하지 않았습니다.

## 통과한 검사

- `npm test`: 17개 통과. Supabase SDK를 연결하는 HTTP 모의 검사 2개, 메일 인증 UI 검사 3개, 쿠키/CSRF/미인증 API 검사 3개, 기존 집계/시간대 검사 5개, 실제 PostgreSQL SQL 검사 4개.
- `npm run build`: 브라우저 정적 파일만 dist에 복사. 서버 SDK/환경변수는 포함하지 않음.
- `node scripts/check-secrets.mjs`: 소스, dist, 로컬 Git 이력에서 비밀키/JWT 패턴을 발견하지 않음. 실제 배포 환경변수 값/원격 배포 로그 확인을 대신하지 않음.
- 실제 SQL: A→B/B→A 읽기·수정·삭제/생성/실행 로그 연결 거절, 상대 자료 변경 없음, 본인 목록만 조회, 요청키 계정별 격리, 기존 완료 중복 방지 유지.
- 실제 SQL: 로그아웃 처리(세션 revoke) 전후 같은 해시 성공/401, 만료한 세션 401.
- 실제 SQL: 직접 DB 표/RPC 권한 거절, 옛 세션 없는 RPC 제거 확인.
- 실제 SQL: 관찰 소유권, 중복 날짜/중복 ID 거절, 규칙 변경의 1·2일차 ID, 3일차 이후 변경 거절, 규칙 변경 전 로그의 3일차 재사용 거절, 6일차 추가 거절.
- 실제 SQL: 계정 삭제가 실행 로그/계획 이력/요청키/관찰/규칙/앱 세션까지 제거하는 것 확인.
- 사용자 제공 T06 백업 복원: 계획 3개, 할 일 15개, 실행 기록 6건, 돌아보기 1건, 계획 이력 4건, 완료 이력 6건의 ID·날짜·값 333개 항목 일치.
- 기존 DB의 본인 계정 귀속 SQL: 기존 계획 값/ID 변화 없이 workspace 한 건만 본인에게 귀속됨.
- Chromium UI: 로그인/가입 전환, 비로그인 자료 화면에서 로그인으로 이동, 관찰 시작 입력창, 계정 화면, 모바일 레이아웃 확인. 로그인한 자료 응답은 화면 검사에 한해 모의 응답을 사용함.
- 메일 인증 API/UI: 실제 SDK를 사용한 모의 응답으로 앱 `/login` 리다이렉트 지정, 서버 인증 확인, 동일 링크 재사용 거절, 응답에 서비스 JWT/확인 값 없음, 앱 쿠키 미발급, 출처 다른 확인 요청 거절, 존재/미존재 계정 재전송 안내 동일 확인. Chromium 모의 응답으로 성공/만료/재전송 안내, 주소에서 확인 값 제거, 데스크톱/모바일 표시 확인.

## 아직 실제 배포에서 확인해야 하는 것

- Supabase Auth 가입/이메일 인증/로그인/중복 가입, 실제 auth.users bcrypt 값 두 개 비교.
- 배포 API에서 같은 쿠키의 로그아웃·비밀번호 변경 전후와 양방향 타인 접근 제한. `scripts/auth-evidence.mjs`로 실제 응답을 저장할 수 있음.
- Vercel 배포 환경/과거 Preview 경로와 원격 Git 브랜치 전체, Console/Network/서버 로그의 비밀값 점검.
- 기존 실제 자료 귀속, 새로고침, 내보내기, 스크립트 문자열 표시.
- 서로 다른 실제 서울 날짜 5일 학습 기록과 계획 규칙 변경, 손계산 대조.

배포를 하지 않은 상태에서 과제7 전체 완료 또는 실제 서비스 보안 검사 완료라고 주장하지 않습니다.

## 일반 계획 UI 검증 (2026-10-01)

자동 검사 18개 통과. 005를 두 번 적용해도 기존 관찰 값이 그대로이고 새 관찰만 일반 지표가 되는 SQL 검사를 추가했습니다. 기존 양방향 소유자 격리·완료 중복 방지·세션·5일 날짜/변경 순서 검사도 통과했습니다.

로컬 브라우저에서 로그인/회원가입 전환, 비로그인 리다이렉트, 여섯 화면, 집계에서 근거 열기, 관찰 시작 모달, 새 계획 모달, 빈 자료 화면, 390px 모바일 가로 넘침을 확인했습니다. 화면 검사에 사용한 로그인/자료 응답은 모의 응답이며, 실제 서버 저장이나 과제 제출용 실사용 증거가 아닙니다. 빌드·JS 문법·diff 공백 검사·로컬 소스/빌드/Git 알려진 비밀값 패턴 검사 통과. 실제 배포 테스트는 별도 진행합니다.

## 캐릭터·완료 안내·계획 삭제 검증 (2026-10-01)

자동 검사 20개 통과. 실제 PostgreSQL 엔진에서 계정별 캐릭터 저장/복원, 타인 owner_id 무시, 허용 목록 검증, 폐기된 세션 거절, 직접 DB 권한 차단, 계정 삭제 시 프로필 삭제를 확인했습니다. 계획 삭제는 타인 계획 404, 확인 문구/버전 검사, 연결 데이터 삭제, 재요청 중복 방지, 다음 계획 유지, 5일 관찰 근거 보존 거절을 확인했습니다.

로컬 브라우저에서 실제 4초 타이머, 이전 타이머가 새 오류를 지우지 않는 동작, 24종 선택과 선택 취소·저장·페이지 재로드, 삭제 취소·잘못된 문구·성공, 모바일 모달/계정 화면을 확인했습니다. 화면 API는 모의 응답을 사용했고 서버 DB 동작은 별도 SQL 자동 검사로 검증했습니다. 한글 폰트는 QA 환경에만 적용하며 소스/배포에 추가하지 않았습니다. 캐릭터는 원본 SVG 24개를 소스에 포함하고 XML 문법 및 화면 렌더링을 확인했습니다.
